# 🎨 Watermark Feature - User Guide

## Quick Start

### Step 1: Upload Your Watermark
1. Scroll to the **"Watermark"** panel in the left column
2. Click **"Upload Watermark Image"**
3. Choose your company logo or watermark (PNG, JPG, etc.)
4. ✅ Your watermark appears in the preview!

### Step 2: Position It
1. **Click and drag** the watermark in the preview window
2. Move it to your preferred location
3. The watermark stays behind the text (never covers it)

### Step 3: Adjust Size & Opacity
1. Use the **"Size"** slider to make it bigger or smaller
   - Default: 30% of page width
   - Range: 10% to 80%
   
2. Use the **"Opacity"** slider to adjust transparency
   - Default: 15% (subtle watermark)
   - Recommendation: Keep between 10-20% for best readability

### Step 4: Lock It
1. Once happy with position, click **"Fix Position"**
2. ✅ Watermark is now locked and won't move accidentally
3. Button shows "✓ Position Fixed"

### Step 5: Export
- **PDF Export**: Watermark included automatically on all pages
- **JSON Export**: Watermark settings saved for later use

## 💡 Best Practices

### Recommended Settings
```
Size: 25-35% of page width
Opacity: 10-20% (15% is ideal)
Position: Center or diagonal corner-to-corner
```

### Image Tips
- ✅ **Use PNG with transparent background** for professional look
- ✅ Keep image resolution reasonable (500x500 to 1000x1000 pixels)
- ✅ Test with actual content to ensure readability
- ❌ Avoid very dark images at high opacity

### Common Watermark Positions

**Center (Default)**
```
Position: Middle of page
Best for: Company logos, certificates
```

**Diagonal**
```
Position: From corner to corner
Best for: "DRAFT", "CONFIDENTIAL" stamps
```

**Bottom Right**
```
Position: Lower right corner
Best for: Subtle branding
```

## 🔧 Controls Explained

### Upload Button
- **First Upload**: Shows "Upload Watermark Image"
- **Change Image**: Shows "Change Image" (replaces current)

### Size Slider
- **Left (10%)**: Very small watermark
- **Middle (30%)**: Standard size ⭐ Recommended
- **Right (80%)**: Very large watermark

### Opacity Slider
- **Left (0%)**: Invisible (why though? 😄)
- **15%**: Perfect balance ⭐ Recommended
- **Right (100%)**: Fully opaque (blocks text - not recommended)

### Fix Position Button
- **Unfixed**: 📌 Fix Position (drag in preview first)
- **Fixed**: ✓ Position Fixed
- Click again to unlock and reposition

### Remove Button
- Completely removes watermark
- Settings are lost (unless saved in JSON export)

## 🚀 Advanced Features

### Save Watermark Configuration
1. Set up your watermark perfectly
2. Click **"Export"** (JSON button)
3. Save the JSON file
4. **Next time**: Click **"Load"** and select that JSON
5. ✅ Watermark restored with exact settings!

### Multi-Page Letters
- Watermark automatically appears on **all pages**
- Same position, size, and opacity throughout
- Consistent professional appearance

### Template with Watermark
1. Create a template
2. Add watermark and configure it
3. Save template
4. **Note**: Watermark settings save with JSON export, not in template database
5. Export as JSON to preserve watermark

## ❓ FAQ

**Q: Can I use any image format?**
A: Yes! PNG, JPG, GIF, WebP all work. PNG with transparency is best.

**Q: Why is my watermark too dark?**
A: Lower the opacity! Try 10-15% for subtle watermarks.

**Q: Can I rotate the watermark?**
A: Not yet, but great idea for future update!

**Q: Does it work in PDF export?**
A: Yes! Watermark is included in PDF with correct opacity.

**Q: Can I have multiple watermarks?**
A: Currently one watermark per letter. Future enhancement!

**Q: What if I want to remove the watermark?**
A: Click the "Remove" button in the Watermark panel.

**Q: Is watermark saved with the template?**
A: Watermark saves with JSON export. Templates store content only.

## 🎨 Design Tips

### Professional Look
- Light opacity (10-15%)
- Center or subtle corner position
- Medium size (25-35%)
- PNG with transparent background

### Attention-Grabbing
- Higher opacity (20-30%)
- Center position
- Larger size (40-50%)
- Bright colors or bold text

### Subtle Branding
- Very light opacity (8-12%)
- Bottom corner position
- Small size (15-25%)
- Company logo in grayscale

## 📝 Example Workflow

### Creating a Branded Template Letter

1. **Load or create template**
   - Select existing template or create new
   - Add subject and body with variables

2. **Upload company logo**
   - Click "Upload Watermark Image"
   - Select company logo (PNG recommended)

3. **Position and size**
   - Drag to center of preview
   - Adjust size to 30%
   - Set opacity to 15%

4. **Test and adjust**
   - Fill in some variable values
   - Check if logo interferes with text
   - Adjust opacity if needed

5. **Lock and save**
   - Click "Fix Position"
   - Export as JSON for future use
   - Click "Export PDF" to generate letter

6. **Reuse anytime**
   - Click "Load" button
   - Select saved JSON
   - All settings restored instantly!
